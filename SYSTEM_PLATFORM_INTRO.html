1. 系統概述

1.1 專案背景

碳權平台是一個專為電動車充電設施管理與碳權交易而設計的綜合性系統。隨著全球對環境保護的重視程度不斷提升，電動車的普及率持續增長，如何有效管理充電設施並量化碳排放減少的效益，成為當前重要的技術課題。

1.2 系統目標

  • 提供完整的充電設施管理解決方案
  • 實現碳權交易的數位化管理
  • 支援多廠商、多設備的統一管理
  • 提供實時監控和數據分析功能
  • 確保數據安全和系統穩定性

1.3 業務價值

核心價值主張

  • 環保效益：促進綠色能源發展，減少碳排放
  • 經濟效益：支援碳權交易，創造經濟價值
  • 管理效益：提升充電設施管理效率
  • 社會效益：推動可持續發展目標

2. 系統架構

2.1 整體架構

系統採用現代化的三層架構設計，包含前端展示層、後端業務層和數據持久層。整體架構具有高可用性、可擴展性和安全性等特點。

前端層 (Presentation Layer)

  • Thymeleaf 模板引擎
  • Bootstrap 4 響應式框架
  • JavaScript 動態交互
  • 國際化支援

後端層 (Business Layer)

  • Spring Boot 2.6.15
  • Spring Security 安全框架
  • JPA/Hibernate 數據訪問
  • JWT Token 認證

數據層 (Data Layer)

  • MySQL 8.0 數據庫
  • Azure 雲端部署
  • 數據備份與恢復
  • 性能監控

2.2 技術棧

技術分類 技術選型 版本 用途說明
後端框架 Spring Boot 2.6.15 現代化Java應用框架
安全框架 Spring Security 5.6.0 認證授權與安全控制
數據持久化 JPA/Hibernate 5.6.0 對象關係映射
認證機制 JWT Token 0.11.5 無狀態認證

3.2 特色功能

系統支援中英文雙語切換，提供本地化的用戶體驗，適應不同地區的用戶需求。包含動態語言切換、本地化日期格式、響應式設計等功能。

數據分析與報表

強大的數據分析功能，提供多維度統計報表，支援圖表展示和趨勢分析。包含多維度數據統計、圖表視覺化、趨勢分析、自定義報表等功能。

4. 核心模組

4.1 用戶管理模組

提供完整的用戶註冊、登錄、權限管理功能。支援角色基礎訪問控制(RBAC)，包含管理員和普通用戶兩種角色。

主要功能：

  • 用戶註冊與登錄
  • JWT Token認證
  • 角色權限管理
  • 密碼加密存儲

4.2 充電站管理模組

完整的充電站信息管理系統，支援GPS定位、狀態監控、電力負載管理，提供直觀的地圖介面展示充電站分布。

數據字段：

  • 充電站ID (主鍵)
  • 廠商ID
  • 充電站名稱
  • GPS座標 (緯度/經度)
  • 充電站功率
  • 城市和地址信息
  • 儲能啟用狀態
  • 電源來源

4.3 充電樁管理模組

詳細的充電樁設備管理，包含設備類型、功率規格、品牌信息，支援複合主鍵設計，確保數據完整性。

複合主鍵設計：

  • 充電樁ID + 連接ID
  • 所屬充電站ID
  • 廠商ID
  • 設備類型和品牌
  • 功率規格 (kW/A/V)
  • 設備狀態

4.4 充電記錄模組

完整的充電交易記錄系統，記錄充電時間、電量消耗、車輛信息，支援碳權標記，為碳權交易提供數據基礎。

交易記錄字段：

  • 交易編號 (主鍵)
  • 廠商ID、充電站ID、充電樁ID
  • 開始時間和結束時間
  • 充電量 (kWh)
  • 車輛信息 (車型、噸位、車牌)
  • 碳權標記 (Y/N)
  • 發票信息

5. 安全機制

5.1 認證機制

JWT Token認證

  • 無狀態認證：基於JSON Web Token的無狀態認證機制
  • Token有效期：12小時 (43200秒)
  • 自動刷新：支援Token自動刷新機制
  • 密碼加密：使用BCrypt加密算法

5.2 授權控制

  • 角色基礎訪問控制 (RBAC)：
    • ROLE_ADMIN：系統管理員權限
    • ROLE_USER：普通用戶權限
  • 資源訪問控制：用戶只能訪問自己的數據
  • API權限控制：基於Spring Security的註解控制

5.3 數據安全

  • SQL注入防護：使用JPA參數化查詢
  • XSS防護：輸入驗證和輸出編碼
  • CSRF防護：Spring Security CSRF保護
  • 敏感數據加密：密碼等敏感信息加密存儲
