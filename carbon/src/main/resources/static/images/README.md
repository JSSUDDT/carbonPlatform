# 系統截圖目錄

本目錄用於存放碳權平台的系統截圖，供用戶手冊使用。

## 截圖清單

### 1. 登錄相關
- `login-page.png` - 登錄頁面截圖
- `register-page.png` - 註冊頁面截圖

### 2. 主要功能頁面
- `stations-management.png` - 充電站管理頁面
- `chargers-management.png` - 充電樁管理頁面
- `transactions-records.png` - 充電記錄頁面
- `station-power.png` - 充電站用電頁面
- `station-map.png` - 充電站地圖頁面

### 3. 系統功能
- `dashboard-overview.png` - 儀表板概覽
- `language-switching.png` - 語言切換功能
- `search-function.png` - 搜尋功能展示

## 截圖要求

### 尺寸規格
- **寬度**: 1200px - 1920px
- **高度**: 根據內容自適應
- **格式**: PNG 或 JPG
- **品質**: 高品質，清晰可讀

### 截圖建議
1. **選擇合適的瀏覽器視窗大小**
   - 建議使用 1920x1080 或更高解析度
   - 確保重要功能區域完整顯示

2. **內容要求**
   - 包含完整的頁面功能
   - 顯示實際的數據內容（可使用測試數據）
   - 突出重要的操作按鈕和功能區域

3. **語言版本**
   - 建議同時提供中文和英文版本的截圖
   - 文件名可加上語言後綴，如 `login-page-zh.png`、`login-page-en.png`

4. **截圖工具**
   - 使用瀏覽器內建的截圖功能
   - 或使用專業截圖工具如 Snagit、Greenshot 等

## 文件命名規範

```
功能名稱-頁面類型-語言版本.png
```

### 範例
- `login-page-zh.png` - 登錄頁面（中文版）
- `stations-management-en.png` - 充電站管理（英文版）
- `station-map-overview.png` - 充電站地圖概覽

## 注意事項

1. **隱私保護**: 截圖中不應包含真實的個人資料或敏感資訊
2. **數據安全**: 使用測試數據進行截圖，避免洩露實際業務數據
3. **版本控制**: 截圖應與系統版本保持一致
4. **備份管理**: 建議保留截圖的原始文件作為備份
