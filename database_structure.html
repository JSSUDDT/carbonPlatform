1. 系統概述

碳權平台是一個基於Spring Boot的Web應用系統，主要功能包括：

  • 充電站管理: 管理充電站基本資訊、地理位置和容量
  • 充電樁管理: 管理充電樁設備資訊和狀態
  • 充電交易: 記錄和管理充電交易資料
  • 電力監控: 監控充電站發電量和用電量
  • 用戶管理: 支援多角色權限管理
技術架構: Spring Boot + MySQL + JPA + JWT + Thymeleaf

3. 資料表結構

3.1 carbon_vendor (供應商表)

欄位名稱 資料類型 長度 是否必填 預設值 說明
vendor_id String 50 是 - 供應商ID (主鍵)
password String 100 是 - 密碼 (BCrypt加密)
status String 1 否 1 狀態 (1:啟用, 0:停用)
role String 20 否 ROLE_USER 角色 (ROLE_ADMIN, ROLE_USER)
create_time String - 否 - 建立時間
update_time String - 否 - 更新時間
說明: 儲存系統用戶資訊，支援角色權限管理。每個供應商可以管理多個充電站。

3.2 carbon_station (充電站表)

欄位名稱 資料類型 長度 是否必填 預設值 說明
station_id String 50 是 - 充電站ID (主鍵)
vendor_id String 50 是 - 供應商ID (外鍵)
station_name String 100 否 - 充電站名稱
station_kwh String 50 否 - 充電站容量(kWh)
city String 50 否 - 城市
address String 200 否 - 地址
storage_enable String 1 否 0 是否有儲能設備 (1:是, 0:否)
power_source String 1 否 1 電力來源 (1:併網/離網 2:太陽光電/離網)
gps_latitude String 50 否 - GPS緯度
gps_longitude String 50 否 - GPS經度
station_status String 1 否 1 充電站狀態 (1:啟用, 0:停用)
create_time String - 否 - 建立時間
update_time String - 否 - 更新時間
說明: 儲存充電站基本資訊，包含地理位置、容量和狀態等。支援地圖顯示功能。

3.3 carbon_charger (充電樁表)

欄位名稱 資料類型 長度 是否必填 預設值 說明
charger_id String 50 是 - 充電樁ID (複合主鍵)
connect_id String 50 是 - 連接器ID (複合主鍵)
station_id String 50 是 - 充電站ID (外鍵)
vendor_id String 50 是 - 供應商ID (外鍵)
charger_type String 10 否 - 充電樁類型
charger_brand String 50 否 - 充電樁品牌
charger_kw String 50 否 - 充電功率(kW)
charger_a String 50 否 - 電流(A)
charger_v String 50 否 - 電壓(V)
charger_status String 1 否 1 充電樁狀態 (1:啟用, 0:停用)
first_enable_date String 10 否 - 首次啟用日期 (YYYY-MM-DD)
create_time String - 否 - 建立時間
update_time String - 否 - 更新時間
注意: 此表使用複合主鍵 (charger_id + connect_id)，因為一個充電樁可能有多個連接器。

3.4 carbon_charge (充電交易表)

欄位名稱 資料類型 長度 是否必填 預設值 說明
trans_no String 50 是 - 交易編號 (主鍵)
vendor_id String 50 是 - 供應商ID (外鍵)
station_id String 50 是 - 充電站ID (外鍵)
charger_id String 50 是 - 充電樁ID (外鍵)
connect_id String 50 否 - 連接器ID
invoice_no String 50 否 - 發票號碼
customer_id String 50 否 - 客戶ID
invoice_date String 20 否 - 發票日期
carbon_credit String 1 否 0 是否同意碳權交易 (1:是, 0:否)
start_time String 20 否 - 開始時間
end_time String 20 否 - 結束時間
kwh String 50 否 - 充電度數(kWh)
car_type String 10 否 - 車輛類型
car_tonnage String 50 否 - 車輛噸位
car_no String 20 否 - 車牌號碼
create_time String - 否 - 建立時間
update_time String - 否 - 更新時間
說明: 儲存充電交易記錄，包含充電時間、度數和車輛資訊。用於統計分析和報表生成。

3.5 carbon_station_power (充電站電力監控表)

欄位名稱 資料類型 長度 是否必填 預設值 說明
id Long - 是 AUTO_INCREMENT 自動遞增ID (主鍵)
vendor_id String 50 是 - 供應商ID (外鍵)
station_id String 50 是 - 充電站ID (外鍵)
station_kwh String 50 否 - 總累積充電度數(kWh)
date_info String 10 否 - 日期 (YYYY-MM-DD)
date_kwh String 50 否 - 當日充電度數(kWh)
create_time String - 否 - 建立時間
update_time String - 否 - 更新時間
說明: 儲存充電站每日電力監控資料，用於統計分析。
