碳權平台 - 用戶使用說明

Carbon Credit Platform - User Guide
版本: 1.0 | 更新日期: 2025年1月

1. 系統簡介

碳權平台是一個專為電動車充電站管理而設計的Web應用系統。本平台提供以下主要功能：

  • 充電站管理: 查看和管理充電站資訊
  • 充電樁管理: 查看和維護充電樁設備資訊
  • 充電記錄監控: 查看充電交易歷史和統計資料
  • 電力監控: 監控充電站的發電量和用電量
  • 地圖導航: 使用互動式地圖查看充電站位置

本系統專為內部企業管理使用而設計，支援多語言介面（繁體中文/英文）。

系統特色：採用現代化Web技術，提供直觀易用的操作介面，支援即時資料更新和多種資料匯出格式。

2. 功能操作指引

2.1 註冊新帳號

功能名稱 註冊新帳號
適用對象 新用戶
操作路徑 系統註冊頁面
使用目的 建立新的廠商帳號以使用系統功能
需填欄位 廠商ID、密碼、確認密碼、用戶角色

操作步驟：

  1. 前往系統註冊頁面：https://appprod.japaneast.cloudapp.azure.com/carbon/register
  2. 填寫廠商ID（vendor_id，將用作登錄名，請使用唯一標識）
  3. 設定密碼並確認密碼
  4. 選擇用戶角色：
    • Regular User - Charging Facility Management（一般用戶）
    • Administrator - Full System Access（管理員）
  5. 點擊「註冊」按鈕完成註冊
重要提醒：廠商ID將用作登錄名，請使用唯一標識。註冊成功後即可使用新帳號登入系統。

2.2 登入系統

功能名稱 系統登入
適用對象 已註冊用戶
操作路徑 系統登入頁面
使用目的 驗證身份並進入系統主介面
需填欄位 廠商ID、密碼

操作步驟：

  1. 前往系統登入頁面：https://appprod.japaneast.cloudapp.azure.com/carbon/login
  2. 輸入您的廠商ID（vendor_id）
  3. 輸入您的密碼
  4. 點擊「登入」按鈕
  5. 系統會驗證您的身份並導向主頁面
系統特色：碳權平台 - 綠色能源，智慧出行。登入成功後即可使用完整的充電站管理功能。

2.3 充電站管理

功能名稱 充電站管理
適用對象 系統管理員、廠商用戶
操作路徑 左側導航欄 > 充電站管理
使用目的 查看和管理所有充電站資訊
主要功能 搜尋、排序、分頁顯示、資料刷新

操作步驟：

  1. 點擊左側導航欄的「充電站管理」
  2. 在搜尋框輸入關鍵字進行搜尋
  3. 點擊欄位標題進行排序
  4. 使用分頁按鈕瀏覽更多資料
  5. 點擊「刷新」按鈕更新資料

2.4 充電樁管理

功能名稱 充電樁管理
適用對象 系統管理員、廠商用戶
操作路徑 左側導航欄 > 充電樁管理
使用目的 查看和管理所有充電樁設備資訊
主要功能 設備狀態監控、技術規格查看、啟用日期管理

2.5 充電記錄

功能名稱 充電記錄
適用對象 系統管理員、廠商用戶
操作路徑 左側導航欄 > 充電記錄
使用目的 查看所有充電交易記錄
主要功能 交易搜尋、充電站篩選、日期範圍篩選、資料排序

操作步驟：

  1. 點擊左側導航欄的「充電記錄」
  2. 使用搜尋功能找到特定交易
  3. 選擇充電站進行篩選
  4. 選擇日期範圍進行篩選
  5. 點擊欄位標題進行排序
  6. 查看交易詳細資訊

2.6 電力監控

功能名稱 充電站用電監控
適用對象 系統管理員、廠商用戶
操作路徑 左側導航欄 > 充電站用電
使用目的 監控充電站用電量和誤差率
主要功能 用電量統計、誤差率計算、即時資料更新

2.7 充電站地圖

功能名稱 充電站地圖
適用對象 所有用戶
操作路徑 左側導航欄 > 充電站地圖
使用目的 互動式地圖查看充電站位置
主要功能 地圖導航、位置搜尋、路線規劃、當前位置顯示

操作步驟：

  1. 點擊左側導航欄的「充電站地圖」
  2. 允許瀏覽器獲取您的地理位置
  3. 地圖會自動定位到您的位置（藍色箭頭）
  4. 點擊充電站標記查看詳細資訊
  5. 使用搜尋框搜尋特定地點
  6. 點擊「查看詳情」連結查看充電站完整資訊

3. 使用技巧

3.1 搜尋技巧

  • 關鍵字搜尋: 使用部分關鍵字即可找到相關資料
  • 組合搜尋: 可同時使用多個條件進行篩選
  • 清除搜尋: 點擊搜尋框旁的清除按鈕重置搜尋條件

3.2 表格操作

  • 排序: 點擊欄位標題可進行升序/降序排序
  • 分頁: 大量資料時使用分頁按鈕瀏覽
  • 每頁顯示: 可調整每頁顯示的記錄數量
  • 匯出: 部分頁面支援資料匯出功能

3.3 瀏覽器建議

  • 推薦瀏覽器: Chrome、Firefox、Edge最新版本
  • 螢幕解析度: 建議使用1920x1080或更高解析度
  • 網路連線: 建議使用穩定的網路連線
  • JavaScript: 請確保瀏覽器已啟用JavaScript

4. 法律條款與責任

重要法律條款

碳權轉移同意條款：廠商確認上傳至本平台的所有充電記錄均已獲得使用者明確同意進行碳權轉移，並承諾遵守相關碳權交易法規。

資料真實性保證條款：廠商保證所上傳的所有資料均為真實、準確且完整，如有虛假資料將承擔相應法律責任。
