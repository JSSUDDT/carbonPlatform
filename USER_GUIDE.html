1. 系統概述

1. System Overview

碳權平台是一個專為電動車充電站管理而設計的Web應用系統。您可以：

The Carbon Credit Platform is a web application system designed for electric vehicle charging station management. You can:

  • 查看充電站資訊: 瀏覽所有充電站的基本資訊和地理位置
  • 管理充電樁: 查看和維護充電樁設備資訊
  • 監控充電記錄: 查看充電交易歷史和統計資料
  • 電力監控: 監控充電站的發電量和用電量
  • 地圖導航: 使用互動式地圖查看充電站位置
  • View Station Information: Browse basic information and geographical locations of all charging stations
  • Manage Chargers: View and maintain charger device information
  • Monitor Charging Records: View charging transaction history and statistics
  • Power Monitoring: Monitor power generation and consumption of charging stations
  • Map Navigation: Use interactive maps to view charging station locations
注意:Note: 系統支援多語言切換，您可以在右上角選擇繁體中文或英文介面。 The system supports multi-language switching. You can select Traditional Chinese or English interface in the top right corner.

2. Account Registration

新用戶需要先註冊帳號才能使用系統功能。註冊過程需要填寫基本資訊並同意相關條款。

New users need to register an account before using system functions. The registration process requires filling in basic information and agreeing to relevant terms.

註冊步驟

Registration Steps

  1. 前往系統登入頁面，點擊「註冊新帳號」連結
  2. 填寫廠商ID（vendor_id）
  3. 設定密碼（至少6位元，最多50位元）
  4. 確認密碼
  5. 必須勾選同意條款：
    • 廠商確認上傳至本平台的所有充電記錄均已獲得使用者明確同意進行碳權轉移，並承諾遵守相關碳權交易法規
    • 廠商保證所上傳的所有資料均為真實、準確且完整，如有虛假資料將承擔相應法律責任
  6. 點擊「註冊」按鈕完成註冊
  1. Go to the system login page and click the "Register New Account" link
  2. Fill in the vendor ID (vendor_id)
  3. Set password (minimum 6 characters, maximum 50 characters)
  4. Confirm password
  5. Must check to agree to terms:
    • Vendor confirms that all charging records uploaded to this platform have obtained explicit user consent for carbon credit transfer and commits to comply with relevant carbon trading regulations
    • Vendor guarantees that all uploaded data is true, accurate, and complete, and will bear corresponding legal responsibility for any false data
  6. Click the "Register" button to complete registration

註冊要求與條款說明

Registration Requirements and Terms

重要提醒：每個廠商ID只能註冊一次，密碼長度需為6-50位元，且必須勾選同意以下兩個條款才能完成註冊：

Important Reminder: Each vendor ID can only be registered once, password length must be 6-50 characters, and you must check to agree to the following two terms to complete registration:

  1. 碳權轉移同意條款：廠商確認上傳至本平台的所有充電記錄均已獲得使用者明確同意進行碳權轉移，並承諾遵守相關碳權交易法規
  2. 資料真實性保證條款：廠商保證所上傳的所有資料均為真實、準確且完整，如有虛假資料將承擔相應法律責任
  1. Carbon Credit Transfer Consent Terms: Vendor confirms that all charging records uploaded to this platform have obtained explicit user consent for carbon credit transfer and commits to comply with relevant carbon trading regulations
  2. Data Authenticity Guarantee Terms: Vendor guarantees that all uploaded data is true, accurate, and complete, and will bear corresponding legal responsibility for any false data

表單欄位：廠商ID（4-50位元，註冊後無法修改）、密碼（6-50位元）、確認密碼（必須一致）、同意條款（必須勾選）。

Form Fields: Vendor ID (4-50 characters, cannot be modified after registration), Password (6-50 characters), Confirm Password (must match), Terms Agreement (must be checked).

法律責任提醒: Legal Responsibility Reminder:
  • 同意條款具有法律約束力，請仔細閱讀後再勾選

註冊成功後: 系統會自動導向登入頁面，您可以使用新註冊的帳號和密碼登入系統。 After Successful Registration: The system will automatically redirect to the login page, and you can log in with your newly registered account and password.

誤差率計算

Error Rate Calculation

誤差率 = (交易累計度數 - 日期充電度數) ÷ 交易累計度數 × 100%

Error Rate = (Transaction Cumulative kWh - Date Charging kWh) ÷ Transaction Cumulative kWh × 100%

滑鼠懸停在誤差率欄位可查看計算方法說明。

Hover over the error rate field to view calculation method explanation.

提示: 充電站用電資料會即時更新，幫助您了解充電站的能源使用效率。 Tip: Station power data updates in real-time, helping you understand the energy efficiency of charging stations.
